# Stock photos

Backgrounds for the photo evidence in the case-family cases (`PhotoMeta.image`). Every photo is a generic
scene with no identifiable face, readable number plate, or business name or logo. Each file was resized to
960 px wide and re-saved with no metadata; the renderer then adds the case's own synthetic EXIF and a visible
"SYNTHETIC" mark. Licences were checked on each file's Commons page (November 2026).

All nine are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), which allows reuse and modification with no
conditions. Credit is given anyway.
